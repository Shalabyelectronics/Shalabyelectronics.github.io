# About me

I started from curiosity — taking things apart, figuring out how they work. My first steps into code were with Python a couple of years ago, but I found where I really wanted to build: the front end.

Today my focus is JavaScript and React — building responsive, interactive interfaces and working with APIs. I'm currently deepening my React skills through hands-on projects and a front-end bootcamp, on my way to becoming a strong front-end developer.

I believe consistency beats intensity. Small steps, repeated daily, compound into things you couldn't have built in a single sprint.
